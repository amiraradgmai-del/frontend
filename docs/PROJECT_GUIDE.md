# راهنمای فنی پروژه چکاه

## فناوری‌ها

- Backend: Python، FastAPI، SQLAlchemy و Alembic
- Frontend: Next.js، React، TypeScript و Tailwind CSS
- AI: بازیابی ترکیبی قوانین و مدل‌های Gemini از مسیر تنظیم‌شده در محیط
- Storage: ذخیره‌ساز فایل با رابط قابل جایگزینی برای فضای محلی یا سازگار با S3

## نقش‌ها

| نقش | دسترسی اصلی |
| --- | --- |
| کاربر | چت‌بات، قوانین، اسناد، کیف پول، اشتراک، مشاور و پشتیبانی |
| ادمین | پشتیبانی، مدیریت مشاوران، پرداخت‌ها و مدیریت صفحات و بلاگ |
| کارشناس مالیاتی | پرونده‌ها، رزروها، تقویم و گزارش جلسه |
| کارشناس شرکت | صف مشاوره شرکت و پرونده‌های ارجاعی |
| مدیر سامانه | دسترسی کامل مدیریتی، تنظیمات، کاربران، محتوا، داده و گزارش‌ها |

## مدیریت بلاگ

ادمین و مدیر سامانه از مسیر `/management/content` می‌توانند:

- مطلب بلاگ یا صفحه ثابت بسازند.
- عنوان، آدرس، دسته‌بندی، برچسب و متن را ویرایش کنند.
- تصویر شاخص تا سقف ۵ مگابایت بارگذاری کنند.
- محتوا را پیش‌نویس، زمان‌بندی یا منتشر کنند.
- نظرهای کاربران را تأیید یا رد کنند.

مطالب منتشرشده در `/blog` نمایش داده می‌شوند.

## پروفایل کاربر

فرم کاربر فقط اطلاعات لازم برای ارائه خدمت و ارتباط را نمایش می‌دهد. فیلدهای تخصصی غیرضروری مانند کد پستی، کد اقتصادی و ایمیل دوم از فرم عمومی حذف شده‌اند. اطلاعات مدیریتی قدیمی برای سازگاری دیتابیس حذف فیزیکی نشده‌اند.

## پشتیبانی

دکمه شناور پشتیبانی فقط در پنل کاربر عادی نمایش داده می‌شود. ادمین‌ها و کارشناسان از صفحات کاری اختصاصی خود برای پاسخ‌گویی استفاده می‌کنند.

## متغیرهای محیطی

فایل‌های `.env.example` فهرست تنظیمات لازم را دارند. پیش از اجرا حداقل دیتابیس، JWT، نشانی فرانت‌اند، سرویس پیامک و کلید AI را تنظیم کنید. هیچ مقدار واقعی را در Git قرار ندهید.

## کنترل کیفیت

```powershell
cd backend
.venv\Scripts\python.exe -m pytest

cd ..\frontend
npm run lint
npm run build
```

## انتشار

1. از دیتابیس و فایل‌های محیطی نسخه پشتیبان بگیرید.
2. تست‌های بک‌اند و Build فرانت‌اند را اجرا کنید.
3. Migrationها را با `alembic upgrade head` اعمال کنید.
4. بک‌اند و فرانت‌اند را جداگانه راه‌اندازی مجدد کنید.
5. سلامت API، ورود، نقش‌ها، بلاگ و بارگذاری تصویر را بررسی کنید.
